Weather Forecast Application 🌦️

Project Description

The Weather Forecast Application is a simple Java-based console application that displays sample weather information for a city entered by the user.

Objectives

- To develop a simple application using Java.
- To get the city name from the user.
- To display weather details in an easy-to-understand format.
- To practice Java basics and user input handling.

Technologies Used

- Java
- Scanner Class
- Standard Input and Output

Features

- Accepts city name from the user.
- Displays temperature.
- Shows humidity percentage.
- Displays wind speed.
- Shows weather conditions.

How to Run

1. Install Java JDK.

2. Save the code as "WeatherForecast.java".

3. Open the terminal in the project folder.

4. Compile the program:
   
   "javac WeatherForecast.java"

5. Run the program:
   
   "java WeatherForecast"

Sample Output

=== Weather Forecast Application ===
Enter City Name: Coimbatore

Weather Report for Coimbatore
Temperature: 30°C
Humidity: 65%
Wind Speed: 12 km/h
Weather Condition: Sunny
